# FC-032 비회원 이름·응답 수정

같은 브라우저로 링크를 다시 열면 기존 쿠키로 본인 응답을 복원한다. 내 응답 수정에서 이름 오타와 응답을 함께 저장한다.
이름이 바뀐 경우에만 기존 응답 PUT에 displayName/expectedDisplayName을 포함하고 성공 후 다시 읽는다.
canEditName=false이면 공유 이름을 편집할 수 없으며 참석 응답은 해당 OPEN 단위에서 계속 수정할 수 있다.
총무 웹도 비회원 참여자 관리에서 이름 정정 API를 호출한다. 실제 비회원 기능과 가상 데모 회원은 구분한다.
총무·다른 창이 먼저 바꿨으면 안내와 최신 상태 확인을 제공한다. 이름 선택만으로 타인 권한을 복구하지 않는다.
다른 브라우저·쿠키 삭제 시 새로 제출하기보다 총무에게 이름/수정할 내용을 알리도록 안내한다.

백엔드 PR54/API v22를 먼저 적용해야 한다. participantId·응답·스푼을 새로 만들지 않는다.
로컬 Vitest 289개 및 production build 통과. 제한된 임시 폴더의 Vite 캐시 읽기 오류 후 정상 환경에서 동일 테스트를 재실행했다.
화면 검증 fixture는 qa/fc028.tsx이며 운영 index.html이 불러오지 않는다. 운영/실기기 확인은 별도다.

390px 가상 응답 화면에서 최초 제출 → 내 응답 수정 → 빈 이름 오류 → 이름/음주 정정 → 최신 상태 재조회 → 확정 후 잠금을 확인했다. qa/fc032-name-corrected.png는 운영 자료가 아닌 로컬 화면 증거다.
