# Apple 자동 이름 이후 웹 약관 확인

Apple 이름을 서버가 자동으로 저장하면 웹의 이름 입력 화면을 거치지 않는다. 이름 화면 안에 있던 약관 동의가 빠지지 않도록 실제 로그인한 계정은 회원 화면을 열기 전에 약관을 확인한다. 이름 입력이 필요한 계정은 기존 화면에서 한 번만 동의한다.

- 기준은 2026-11-10 Vercel 운영 대시보드에서 확인한 `02e98c46d0ab6cd8f81f448b414234f261a36f8b`다.
- 이름이 있는 계정에는 이름 입력 없는 약관 화면과 로그아웃을 제공한다.
- 동의는 브라우저 localStorage에 계정 ID와 약관 버전별로 기록한다. 저장소가 제한되면 현재 화면에서만 동의를 유지한다. 서버의 동의 이력이나 앱의 동의 기록을 대신하지 않는다.
- 공개 안내와 로그인 전 화면, 목데이터 체험은 유지한다. 약관·개인정보 안내는 Apple 최초 동의 이름과 기본 표시 이름 사용에 맞춘다. UGC 금지와 신고 처리 조건은 유지한다.

검증: 전체 270개 테스트, TypeScript·운영 API 설정 빌드, 변경 파일 ESLint, diff 검사 통과. 가상 계정의 실제 브라우저에서 체크 전 진행 불가, 체크 후 진입, 새로고침 후 유지, 다른 계정 재동의, 로그아웃 화면 전환을 확인했다. 실제 소셜 계정 로그인 완료를 검사한 것은 아니다.

별도 확인: 운영 main에는 이전 `codex/guest-name-correction`의 `GuestFlow`와 차수별 인원 수정이 포함되어 있지 않다. 이번 로그인 수정은 현재 운영본에만 추가했으며 해당 기능을 임의로 복원하지 않았다. 다음 출시에서는 이 두 개발 브랜치와 운영 배포 경로를 별도로 대조해야 한다.
